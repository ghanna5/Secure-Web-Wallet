# Secure-Web-Wallet

Flask web apps from CPSC 455 (Web Security) at Cal State Fullerton, served behind nginx.

- `project-2`: user registration and login with sessions and a protected page
- `project-3`: a digital wallet (create a wallet, add money, transfer money) with bcrypt password hashing and CSRF protection

## Run
```
pip install flask flask-bcrypt flask-wtf
python app.py
```
